# Contributing to DevAnalyzeX

Thanks for your interest in contributing to DevAnalyzeX.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Test your changes
6. Open a Pull Request

## Branch Naming

Use descriptive branch names:

- `feature/your-feature`
- `fix/your-fix`
- `docs/your-change`
- `refactor/your-change`

## Pull Requests

Please include:

- What changed
- Why the change was needed
- How you tested it

Keep pull requests focused and easy to review.

## Issues

Before creating an issue, check whether a similar issue already exists.

For bugs, include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots

For feature requests, explain the problem the feature would solve.

## Code Quality

Please keep code readable, maintainable, and consistent with the existing project structure.

Thank you for contributing!
